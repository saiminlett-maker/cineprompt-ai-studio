1

Google AI Studio ဝဘ်ဆိုက်သို့ သွားပါ

အပေါ်ရှိ ခလုတ် သို့မဟုတ် aistudio.google.com/app/apikey သို့ သွားပြီး မိမိ၏ Google Account (Gmail) ဖြင့် ဝင်ရောက် (Sign In) ပါ။

ဝဘ်ဆိုက် ဝင်မရပါက VPN (Singapore သို့မဟုတ် US) ကို ခေတ္တ ဖွင့်ပေးပါ
2

"Create API key" ခလုတ်ကို နှိပ်ပါ

စာမျက်နှာပေါ်ရှိ အပြာရောင် "Create API key" (သို့မဟုတ် Get API Key) ခလုတ်ကို နှိပ်ပါ။

3

"Create API key in new project" ကို ရွေးချယ်ပါ

ပေါ်လာသော Box တွင် Create API key in new project ကို ရွေးချယ်လိုက်ပါက Google က API Key အသစ်တစ်ခု ထုတ်ပေးပါမည်။

4

ထွက်လာသော API Key ကုဒ်ကို Copy ယူပါ

ထွက်ပေါ်လာသော AIzaSy... ဖြင့် စတင်သည့် Key ကုဒ်ရှည်ကို "Copy" နှိပ်၍ ကူးယူပါ။

5

ဤ App ထဲရှိ Settings တွင် Paste ထည့်၍ သိမ်းဆည်းပါ

ဤ App ၏ Gemini Settings ထဲသို့ ပြန်သွားပြီး Google Gemini API Key အကွက်ထဲတွင် Paste ချပါ။ ထို့နောက် "API Key စစ်ဆေးမည်" ကို နှိပ်၍ စစ်ဆေးပြီး "သိမ်းဆည်းမည် (Save)" ကို နှိပ်ပါက အောင်မြင်စွာ ချိတ်ဆက်ပြီး ဖြစ်ပါသည်!
